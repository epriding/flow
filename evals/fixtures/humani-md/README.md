# Reading list project

This project will let a person save article links in a private reading list and mark articles as read. No sharing, recommendations, or background fetching is planned. Users need to sign in. Duplicate links should not create duplicate entries for the same person.

There is no application code or existing specification yet. Do not invent a framework, benchmark, or completed verification result. Save the technical specification to SPEC.md when its readable companion has been approved. The implementation plan will eventually live at tasks/plan.md.

Specs, plans, and their readable companions are temporary implementation documents. Retain them while the work or review remains open. Creation of both pairs is authorized for this exercise; approval of their contents is a separate decision.
